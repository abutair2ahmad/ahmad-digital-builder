# Ecommerce Brand Identity

## When to Use This Skill

Use this skill when you need to:
- Define a store's personality and positioning
- Create a visual identity for an online brand
- Improve trust and recognition across social and storefront
- Align product pages, packaging, and marketing with one story

## Core Principle

A STRONG BRAND IS NOT JUST A LOGO — IT IS A CLEAR PROMISE THAT PEOPLE CAN RECOGNIZE, TRUST, AND REMEMBER.

## Practical Experience Layer

- Brand identity should be built around the customer problem and the promise, not just aesthetics.
- A premium brand feels clear, consistent, and easy to trust.
- Differentiate through tone, details, and customer experience, not noise.

## Phase 1: Brand Brief

### Required Inputs

| Input | What to Ask | Default |
|-------|------------|---------|
| Brand name | "What is the brand called?" | Use placeholder |
| Target customer | "Who is the ideal customer?" | Broad audience |
| Core promise | "What main problem does this brand solve?" | Clear value proposition |
| Style influence | "Do you prefer luxury, minimal, bold, soft, premium, or modern?" | Premium minimal |
| Product category | "What are you selling?" | General ecommerce |
| Brand values | "What values should the brand communicate?" | Trust, quality, clarity |

GATE: Confirm the brand promise before selecting colors and typography.

## Phase 2: Brand Positioning

### Brand Statement Template

```
## Brand Positioning

For [customer], who [need/problem], [brand name] provides [offer] that [unique benefit].
Unlike [alternative], we [difference / advantage].
```

### Tone of Voice

```
## Tone Guide

- Friendly / confident / premium / minimal / helpful
- Use short, direct sentences
- Avoid jargon unless essential
- Speak in a way that feels human and trustworthy
```

## Phase 3: Visual Identity

### Visual System

```
## Visual Identity

- Primary color: [X]
- Secondary color: [X]
- Accent color: [X]
- Typography: [Heading font + body font]
- Mood: [Warm / premium / clean / bold]
- Imagery style: [Lifestyle / product-focused / editorial]
```

### Design Rules

- Keep backgrounds uncluttered and premium.
- Use consistent spacing and layouts.
- Use a limited palette to keep the brand recognizable.
- Maintain a clear hierarchy between headings, prices, CTA buttons, and trust points.

## Phase 4: Brand Experience

### Store Touchpoints

Map brand consistency across:
- Homepage
- Product pages
- Social media
- Packaging
- Email marketing
- WhatsApp or customer support tone
- UGC and testimonials

### Messaging Checklist

- Value is obvious
- Tone is consistent
- Benefits are stated, not just product features
- The brand feels trustworthy and premium

## Anti-Patterns

- Confusing brand promise
- Overly generic design that could belong to any store
- Too many colors or styles at once
- Copy that sounds like a catalog instead of a brand
- Inconsistent tone across storefront and social

## Recovery

- If the store feels generic: sharpen the positioning and visual system.
- If trust is weak: simplify the copy and add proof elements.
- If the brand is not memorable: reduce the design to fewer, more distinctive elements.
