# Conversion UX Audit

## When to Use This Skill

Use this skill when you need to:
- Review a storefront or landing page for conversion gaps
- Diagnose where customers hesitate or leave
- Improve clarity, trust, and decision-making flow
- Identify friction in navigation, trust, and checkout

## Core Principle

A WEAK CONVERSION EXPERIENCE DOES NOT ALWAYS MEAN A BAD PRODUCT — OFTEN IT MEANS THE STORE MAKES THE CUSTOMER WORK TOO HARD TO TRUST, UNDERSTAND, OR BUY.

## Practical Experience Layer

- Audit from the customer's perspective, not from internal assumptions.
- A conversion problem usually comes from friction in a small number of steps.
- Prioritize fixes that reduce uncertainty first, then optimize speed and elegance.

## Phase 1: Discovery

### Required Inputs

| Input | What to Ask | Default |
|-------|------------|---------|
| Store URL or page | "What page or store should be audited?" | Single landing page |
| Goal | "What action are you optimizing?" | Purchase |
| Audience | "Who is the customer?" | General audience |
| Existing data | "Do you have drop-off, bounce, or analytics data?" | Not yet |
| Channel | "Organic, paid, social, or direct?" | Mixed |

GATE: Confirm the main conversion goal before leading the audit.

## Phase 2: UX Review

### Audit Checklist

```
## Conversion Friction Audit

- Is the offer clear in the first 3 seconds?
- Does the user know what to do next?
- Are prices and shipping clear?
- Do trust signals appear before the CTA?
- Is the page readable on mobile?
- Is navigation simple and intentional?
- Does the product page reduce uncertainty?
- Is the checkout flow minimal and calm?
```

### Review Areas

- Hero and promise clarity
- Product page information depth
- CTA placement and repetition
- Trust elements and reviews
- Navigation and category clarity
- Mobile usability
- Cart and checkout friction

## Phase 3: Improvement Plan

### Priority Fixes

Prioritize in this order:
1. Remove friction and confusion
2. Improve trust and clarity
3. Improve product value communication
4. Strengthen CTA flow and hierarchy
5. Optimize upsells and bundles

### Sample Improvement Output

```
## Recommended Improvements

- Move price above fold
- Add social proof near primary CTA
- Simplify product description to benefit-led copy
- Reduce page clutter on mobile
- Add shipping expectations and return policy earlier
```

## Phase 4: Validation

Track after changes:
- Conversion rate
- Add to cart rate
- Cart abandonment rate
- Bounce rate
- Scroll depth and CTA clicks

## Anti-Patterns

- Too much visual noise
- Hidden policy or pricing information
- Weak CTA hierarchy
- Product pages with no proof
- Checkout flow requiring excessive steps

## Recovery

- If customers do not understand the offer: improve the headline and hero copy.
- If they hesitate: add trust, policy, and more proof.
- If they leave during checkout: simplify steps and reduce friction.
- If the store feels cluttered: remove non-essential sections and prioritize conversion flow.
