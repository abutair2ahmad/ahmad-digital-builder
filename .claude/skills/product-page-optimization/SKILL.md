# Product Page Optimization

## When to Use This Skill

Use this skill when you need to:
- Improve conversion on a product page
- Rewrite product copy for clarity and trust
- Improve product photography and layout
- Add upsells, bundles, and social proof
- Increase average order value and customer confidence

## Core Principle

A PRODUCT PAGE DOES NOT NEED TO TELL EVERYTHING — IT NEEDS TO REDUCE DOUBT, CLARIFY VALUE, AND MAKE THE NEXT STEP FEEL SAFE.

## Practical Experience Layer

- Customers buy when they understand the benefit and feel reassured.
- Show the product in context, not only in isolation.
- Use proof triggers: reviews, quality, guarantees, shipping clarity, returns, usage examples.

## Phase 1: Product Brief

### Required Inputs

| Input | What to Ask | Default |
|-------|------------|---------|
| Product name | "What is the product?" | Unknown |
| Ideal customer | "Who is it for?" | General customers |
| Problem solved | "What pain point or outcome does it help with?" | Broad benefit |
| Price | "What is the current price?" | Needs review |
| Photos | "Do you have product images and lifestyle shots?" | Minimal |
| Proof | "Reviews, badges, warranties, or guarantees?" | Needs development |

GATE: Confirm what makes the product worth buying before rewriting the copy.

## Phase 2: Product Story

### Product Title Formula

```
[Product Name] + [Main Benefit] + [Target Audience]
Example: Anti-Aging Serum for Sensitive Skin – Daily Hydration & Glow Support
```

### Product Description Structure

```
## Product Description

- Problem or need
- What the product is
- Benefits and outcomes
- Key features
- How to use it
- Why it is special
- Trust and proof
```

### Feature-to-Benefit Translation

```
Feature: 24-hour hydration
Benefit: skin stays fresh and comfortable all day
```

## Phase 3: Conversion Elements

### Product Page Checklist

```
## Conversion Checklist

- Clear hero image gallery
- Benefit-driven headline
- Price visible early
- Shipping and returns info visible
- Variant selector easy to understand
- Trust badges near CTA
- Reviews near relevant section
- Upsell or bundle section
- FAQ final section
```

### Proof Elements

- Reviews and ratings
- Before/after visuals
- Guarantees and return policy
- Brand quality standards
- Social proof from real usage

## Phase 4: Optimization Loop

### What to Test

- Headline variations
- CTA wording
- Image sequence
- Review placement
- Bundle offer placement
- Shipping messaging type

### Metrics to Track

- Conversion rate
- Add to cart rate
- Bounce rate from product page
- Average order value
- Product page scroll depth

## Anti-Patterns

- Long paragraphs with no benefit-led structure
- Too many CTA buttons competing with each other
- Missing reviews or proof
- Product photos that are too small or low quality
- Shipping or return information hidden below the fold

## Recovery

- If conversion is weak: simplify the layout and strengthen trust elements.
- If customers hesitate: explain benefits more clearly and reduce uncertainty.
- If product seems generic: sharpen the positioning and add proof.
