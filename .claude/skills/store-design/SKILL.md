# Store Design

## When to Use This Skill

Use this skill when you need to:
- Design or redesign an ecommerce storefront
- Structure homepage, collection pages, and product pages
- Improve visual hierarchy and conversion flow
- Create a consistent brand look for a shop
- Build a store that feels premium and trustworthy

## Core Principle

A STORE SHOULD SELL WITHOUT CONFUSION — THE CUSTOMER MUST UNDERSTAND THE OFFER, TRUST THE BRAND, AND KNOW EXACTLY WHAT TO DO NEXT.

## Practical Experience Layer

- Start from the offer, not from decoration.
- Design for mobile-first behavior and scanability.
- Use a consistent visual system: type, spacing, color, cards, buttons.
- Every section must answer one of: why this brand, what is sold, why it is valuable, why trust it, what to do next.

## Phase 1: Brief

### Required Inputs

| Input | What to Ask | Default |
|-------|------------|---------|
| Brand name | "What is the store name and niche?" | Unknown |
| Offer | "What do you sell?" | Broad product range |
| Audience | "Who is the target customer?" | General shoppers |
| Primary goal | "What is the main action: buy, book, subscribe, collect leads?" | Sales |
| Style direction | "What mood should the store feel like?" | Clean premium |
| Existing assets | "Do you have logo, products, photos, colors?" | Use neutral system |

GATE: Confirm the store objective before creating the layout.

## Phase 2: Store Architecture

### Homepage Blueprint

```
## Homepage Structure

1. Hero with main promise + CTA
2. Social proof / trust strip
3. Bestsellers / category highlights
4. Why choose us section
5. Value proposition blocks
6. Customer reviews
7. Brand story / mission
8. Final CTA / email capture / FAQ
```

### Collection Page Blueprint

```
## Collection Template

- Header image or banner
- Short category description
- Filter toolbar
- Product grid with clear pricing
- Benefit/feature callouts
- Social proof near top
- CTA to shop more or contact
```

### Product Page Blueprint

```
## Product Page

- Product name + price
- Clear image gallery
- Benefit-led description
- Key features in bullets
- Size/variant selector
- Delivery & returns info
- Trust badges
- CTA area + urgency/trust copy
- Related products / upsells
```

GATE: Approve the structure before visual design begins.

## Phase 3: Conversion Design

### Layout Principles

- Use a single primary CTA per section.
- Make price and shipping clarity obvious.
- Build trust before demand-heavy sections.
- Keep categories simple and easy to browse.
- Design for fast decision-making.

### High-Conversion Sections

``` 
## Essential Store Elements

- Hero with clear promise
- Reviews and testimonials
- Guarantee or return policy
- Delivery clarity
- FAQ and support access
- Exit-intent or sticky cart CTA
- Cross-sell and bundles
```

### Design System

```
## Brand System

- Primary color: [X]
- Secondary color: [X]
- Accent color: [X]
- Typography: [Headlines / body]
- Buttons: Primary / secondary
- Border radius: [X]
- Card style: [Minimal / soft / luxury]
```

## Phase 4: Polish

### Store Review Checklist

- Mobile readability
- Page load clarity
- Product information completeness
- CTA visibility above the fold
- Trust signals present
- Consistent brand identity across pages

### Success Metrics

Track metrics like:
- Add to cart rate
- Conversion rate
- Bounce rate by landing page
- Average order value
- Product page time on page

### Launch Readiness

- Review pricing and promotions
- Test mobile checkout flow
- Confirm shipping and delivery policy
- Validate contact and support section
- Review all product images and copy

## Anti-Patterns

- Too many competing CTAs on one screen
- Overly generic templates with no brand personality
- Hidden pricing or vague delivery messaging
- Weak product photography
- Long cluttered pages with no clear flow

## Recovery

- If the store feels confusing: simplify the structure and reduce page elements.
- If customers do not trust the store: add reviews, policies, guarantees, and clearer messaging.
- If conversion is weak: improve the hero, CTAs, and product page clarity first.
- If the brand feels generic: increase visual distinction and stronger positioning.
